# رسّام+ — المرحلة 1

## الإعداد (مرة واحدة)
1. Firebase Console ← Authentication ← Sign-in method: فعّل **Google** و**Email/Password** و**Anonymous**.
2. Authentication ← Settings ← Authorized domains: أضف دومين Vercel (مثل `your-app.vercel.app`).
3. Realtime Database ← Rules: الصق محتوى `database.rules.json` ثم Publish.
4. Realtime Database ← Data: انسخ رابط القاعدة. لو غير `https://sawe-317bb-default-rtdb.firebaseio.com` عدّل `databaseURL` في `index.html`.

## التشغيل محليًا
`npx serve .` (لا تفتح الملف بـ file:// لأن تسجيل Google لا يعمل هكذا).

## النشر على Vercel
ارفع المجلد إلى GitHub ← Vercel ← Import ← Framework: Other ← Deploy (لا يحتاج build).

## اختبار على موبايلين
1. موبايل A: ادخل كضيف ← أنشئ غرفة عامة. موبايل B (حساب مختلف): تظهر في "الغرف العامة" ← دخول.
2. ارسم من A: يظهر الخط عند B أثناء الرسم، ثم يثبت. جرّب تراجع ومسح (الأدمن فقط).
3. أنشئ غرفة خاصة ← زر "دعوة" ← افتح الرابط على B. جرّب نفس الرابط بدون الكود: يجب أن يُرفض.
4. دردشة من الطرفين، ثم رسائل سريعة متتالية: بعضها يُرفض (حد 0.7 ثانية).
5. الأدمن: كتم، ثم طرد لاعب. بعد الطرد لا يستطيع الدخول مجددًا.
6. اقفل التبويب ثم افتح الرابط: الرسم والمحادثة مستعادان من القاعدة.
7. اقطع الإنترنت: النقطة بجانب اسم الغرفة تصبح حمراء، وتعود خضراء عند الاتصال.

## حدود معروفة
- سعة الغرفة تُفحص من العميل فقط (قواعد RTDB لا تعدّ الأبناء).
- لا يوجد عدّاد لاعبين في قائمة الغرف العامة بعد.
- الكتابة أثناء انقطاع الإنترنت لا تُخزَّن محليًا بعد إغلاق الصفحة.
